# Algorithm Challenge #41 – Check if an Array is Palindrome

🧮 Problem Description  
-
This program fills an integer array with predefined values and checks whether the array is a **Palindrome** or not.

A palindrome array reads the same from left to right and from right to left.

Example:  
Input Array:  
10 20 30 20 10  

Output:  
Yes, the array is a Palindrome

This challenge strengthens understanding of array indexing, comparison logic, and loop-based algorithms in C++.
